# Gabrielle & Erick's Gifts

Crie e gere o site completo no Lovable para o “Chá dos Noivos” de Gabrielle e Erick.

IMPORTANTE:

Este projeto deve ser entregue funcional de ponta a ponta, incluindo frontend, backend, persistência de dados, área administrativa, controle de convidados, controle de presentes e reservas. Não quero apenas um protótipo visual.

O projeto deve ser pensado MOBILE-FIRST, pois a maioria absoluta dos convidados acessará pelo celular. Também deve funcionar perfeitamente em tablets e desktops.

==================================================

1. CONTEXTO DO PROJETO

==================================================

O site será exclusivo para um único casal:

Gabrielle e Erick

Não é uma plataforma SaaS para vários casais.

O objetivo é permitir que amigos e familiares convidados para o Chá dos Noivos escolham presentes físicos que desejam dar ao casal.

Não haverá:

- pagamento online;

- checkout financeiro;

- integração com lojas;

- preços;

- links para comprar produtos;

- produtos digitais.

O site servirá para registrar quais presentes e respectivas quantidades cada convidado se comprometeu a presentear.

O fluxo principal deve ser extremamente simples, acolhedor e intuitivo:

1. Convidado acessa seu link personalizado.

2. Visualiza uma apresentação de Gabrielle e Erick.

3. Visualiza a lista de presentes ainda disponíveis.

4. Escolhe um ou vários presentes.

5. Define a quantidade de cada presente.

6. Visualiza um resumo da seleção.

7. Informa/confirma nome e WhatsApp.

8. Confirma os presentes.

9. O sistema registra imediatamente a reserva.

10. As quantidades disponíveis são atualizadas.

11. O convidado visualiza uma mensagem de agradecimento e informações relacionadas ao Chá dos Noivos.

36. BACKEND E PERSISTÊNCIA

==================================================

Precisamos evitar custo recorrente.

Preferência principal:

implementar backend em Node.js/TypeScript ou solução equivalente e utilizar SQLite como persistência se o ambiente de hospedagem permitir armazenamento persistente confiável.

IMPORTANTE:

SQLite somente deve ser utilizado caso o ambiente de produção ofereça disco/volume persistente.

Não utilizar SQLite em armazenamento efêmero que seja apagado em restart ou deploy.

Se o ambiente disponibilizado pelo Lovable não garantir persistência de arquivos:

usar automaticamente uma alternativa gratuita e confiável de banco de dados, preferencialmente Supabase Free Tier ou solução gratuita equivalente.

Objetivo:

ZERO custo recorrente para o volume esperado deste evento.

Não sacrificar integridade dos dados apenas para evitar banco.

Convidado seleciona mais unidades do que estão disponíveis.

Sistema bloqueia.

Dois convidados tentam reservar simultaneamente a última unidade.

Administrador abre a mesma reserva.

Pessoa acessa /admin sem autenticação.

Resultado:

Não consegue acessar dados.

Link de convite inválido.
